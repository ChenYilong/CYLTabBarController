# Reply greeting (tag: `reply-greeting`)

Added 2026-11-28 by the owner. Applies to every reply in this repository.

1. Start every reply with a greeting, then give the answer.
2. Format: `Hi, <OS>/<folder>:`
   - `<OS>`: the operating system of the session (`macOS`, `Windows`, `Linux`).
   - `<folder>`: the name (last path component) of the session's working folder.
3. Example: a macOS session whose folder is `/Volumes/obsidian/chenyilong/chenyilong/CYLTabBarController` starts its
   reply with `Hi, macOS/CYLTabBarController:`.
