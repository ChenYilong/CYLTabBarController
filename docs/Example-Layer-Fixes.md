# Example-layer fixes

Bugs are fixed in the core: the code published to a package manager (CocoaPods, Swift Package Manager, Maven /
Gradle, npm, pub.dev, ohpm, the WeChat Mini Program component). A fix only in an example is the worst option and is
made only after the owner agrees (AGENTS.md, "Code rules"). Each such fix gets a row here explaining why the core could
not fix it.
