# Example-GIF

| 中文 | English |
|:---|:---|
| 演示 GIF Tab 图标的不同设置，见 [docs/GIF-Animation.md](../docs/GIF-Animation.md)。第 1、2 个 Tab 使用动画 key，选中时播放一次；第 3 个 Tab 作为普通图片传入，一直循环；第 4 个 Tab 是静态图片。第一个 Tab 导航栏右侧的按钮可以切换扁平样式。 | Shows the different settings of a GIF tab icon, see [docs/GIF-Animation.md](../docs/GIF-Animation.md). Tabs 1 and 2 use animation keys and play once when selected; tab 3 is given as a plain image and keeps looping; tab 4 is a static image. The navigation bar button of the first tab switches to and from FlatDesign. |

```sh
cd Example-GIF && pod install && open GIFApp.xcworkspace
```
