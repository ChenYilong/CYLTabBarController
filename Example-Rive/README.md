Integrated with CocoaPods: `pod 'CYLTabBarController/Rive'`, which also brings RiveRuntime. |
| 只有 `RiveApp/` 中的文件是本示例自己的；Tab 的定义与 Rive 属性（`TabItems.swift`）、课程页面、`.riv` 文件、字体与图片都直接引用 `../Example-SwiftUI-Rive/AnimatedApp`，不复制。各 Tab：首页（`HomeView`）、侧边菜单（Rive 图标）、引导页（PlusButton 的页面：Rive 按钮与背景，打开登录页）、UIKit 测试列表（所有 Swift Demo 共用的 [`CYLSettingsDemoTableViewController`](../Example-Shared/CYLSettingsDemoTableViewController.swift)，上方的 [`RiveMenuButtonDemoView`](RiveApp/RiveMenuButtonDemoView.swift) 用 `CYLTabBarItemAnimationFactory` 在 UIKit 中播放 `menu_button.riv`）、登录页（Rive 结果与彩带）。 | Only the files in `RiveApp/` are this demo's own; the tab definitions and Rive attributes (`TabItems.swift`), the course's screens, `.riv` files, fonts and images are referenced from `../Example-SwiftUI-Rive/AnimatedApp`, not copied. The tabs: home (`HomeView`), the side menu (Rive icons), onboarding (the plus button's page: Rive button and background, opening sign-in), the UIKit test list ([`CYLSettingsDemoTableViewController`](../Example-Shared/CYLSettingsDemoTableViewController.swift), shared by every Swift demo, with [`RiveMenuButtonDemoView`](RiveApp/RiveMenuButtonDemoView.swift) above it playing `menu_button.riv` in UIKit through `CYLTabBarItemAnimationFactory`), and sign-in (Rive result and confetti). |

The code (`SVGATabIcons.swift`) and the SVGA files (`SVGAAssets/`, Apache 2.0) come from Example-SwiftUI-Rive, like `TabItems.swift`; the Podfile also brings `pod 'CYLTabBarController/SVGA'`. See [docs/SVGA-Animation.md](../docs/SVGA-Animation.md). |
