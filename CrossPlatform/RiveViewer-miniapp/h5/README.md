# Rive 预览台 H5

独立浏览器版 Rive 预览与托管前端。旧 `/rive-viewer/` 只写入当前浏览器的 IndexedDB；托管根域名会上传用户主动选择或拖入的文件，并在完成后生成公开链接。

## 功能

- 批量导入、浏览器本地文件库、公开链接、萌萌森林动物身份评论、评论与文件归档恢复；H5 不提供永久删除。
- 画板、时间轴、状态机、输入和画面参数位于同一详情页，不分 Tab。
- 播放、暂停、重置、倍速、缩放方式、画布背景和声音开关。
- 默认使用 WebGL2 / Rive Renderer 呈现柔和内阴影与虚化，参数区最后可切换“WebGL2 / 兼容模式”；WebGL2 初始化或运行失败会自动降级 Canvas2D 并显示 Toast。
- 渲染和指针共用同一 Fit 矩阵，支持高 DPI Canvas 点击、完整/铺满和 Listener 交互；JOJO 托管版默认“完整”，旧本地版仍默认“铺满”。
- 加载阶段、百分比、首帧耗时、FPS 与移动端渲染质量档位。
- H5 渲染质量默认高清；复杂文件的画板目录懒加载、DPR / 帧率限制和资源释放继续生效。
- 详情左上角与 `Esc` 返回首页；公开页使用 `/<3 位短码>`，旧 `/s/<短码>` 由 Nginx 跳转。
- 托管首页、详情页和桌面侧栏加号都支持选择或拖放；首个文件先从本机立即打开，预览与云端上传并行。同一批文件顺序上传，每个文件行独立显示电脑、上云箭头、云勾或失败图标，百分比、错误与重试在行内展开，不再显示独立完成卡片。
- 服务端公开中、本机文件和浏览器最近公开记录合并为一个按最近打开、评论或上传时间排序的列表；桌面详情保留 `184px` 窄侧栏，当前项使用独立 `3px` 圆角黄色竖线，顶部“＋”复用同一上传入口，黄色按钮内的加号固定为 `#0b0f14` 近黑色。详情侧栏切换文件只改变选中态，不重新排序或自动展开状态。已归档文件通过首页小按钮打开弹窗恢复，不直接占用主页高度；数量是无黄色强调的普通灰色数字。
- 控制区第一栏显示最新绑定、播放、状态切换或 Rive Event，点击展开当前文件会话最近 `200` 条；事件不上传、不持久化，OpenUrl 不自动打开。
- 首页右上角快捷键图标在桌面 Hover 或键盘聚焦时直接展示，触屏仍支持点击固定；固定态 `Esc` 优先关闭浮窗。详情页右上角只保留下载与复制分享链接。
- 托管详情点击“复制分享链接”后，按钮原位变为普通深色样式、打钩与“已复制”，约 `2.2s` 后复位；刚完成上传的本地文件也会立即生成入口，旧 `/rive-viewer/` 本地模式不显示。
- 新浏览器打开公开文件时按 `Content-Length` 展示真实下载百分比；20 秒未收到响应或 30 秒无新字节时显示可重试错误。下载完成后先进入播放器，再在后台记录最近查看，避免 IndexedDB 阻塞首帧。
- 标题旁显示 `for JOJO` 小字，该托管版本也称“JOJO 版”或“叫叫版”；首页底部只显示纯文本“反馈意见：杨皓棱”。
- 评论无需填写名字。浏览器随机访问标识会稳定映射为 32 组动物昵称和 `32×32px` 蜡笔头像；同一浏览器保持不变，归档评论默认折叠并可由任何人恢复。
- 最近查看或评论的公开文件把元信息与 `160×120 WebP` 缩略图保存在当前浏览器，最多 `20` 条，不缓存远端 `.riv` 本体。
- H5 不再预置两份示例；微信小程序内置示例保持不变。

## 本地运行

```bash
npm ci
npm run dev
```

旧本地基址入口：<http://localhost:5173/rive-viewer/>。托管根路径开发使用 `RIVE_VIEWER_BASE=/ npm run dev`，API 默认代理到 `127.0.0.1:8097`。

使用 Node 22 LTS（见 `.nvmrc`）。H5 只保留 Vite 静态构建，不依赖 Next、Cloudflare 或常驻 Node 服务。

## 验证

```bash
npm run lint
npm run check
```

构建会把播放器、WebGL2 与 Canvas2D 运行时分别拆包，并为 JS、CSS、SVG 和两份版本化 WASM 生成 Brotli/Gzip 文件。

## 部署

- 托管平台：<https://rive.mikeywa.site/>
- 旧本地预览：<https://mikeywa.site/rive-viewer/>

两个域名均由腾讯云轻量服务器上的 Nginx 托管并使用独立原子发布目录。托管前端发布到 `/var/www/rive-host/releases/<时间戳>`，旧本地预览发布到 `/var/www/rive-viewer/releases/<时间戳>/rive-viewer`；服务器连接别名为 `ssh mikeywa-rive`，对应规则为 `deploy/nginx-rive-host.conf` 与 `deploy/nginx-rive-viewer.conf`。
