# 设计规范

当前发布基线为 `1.0.7`；性能信息、渲染档位和画布手柄反馈在小程序与 H5 中保持相同认知。

## 详情快捷键反馈

桌面与手机详情页的右上角均保留键盘图标。下载与上传新版本的按钮气泡按系统显示 ⌘ E/U 或 Ctrl E/U，复制链接统一显示 L，归档显示 Delete；气泡支持悬停与键盘聚焦，通过 Portal 挂到 body 并使用手动 Popover 顶层，脱离预览区域的层叠与裁切；位置避让窗口边缘，滚动、点击和 Esc 关闭。320px 窄屏将复制按钮收为图标，保留无障碍名称。文件组合快捷键在捕获阶段取消默认行为，原播放器快捷键仍在冒泡阶段处理，尊重控件自身按键。

## JOJO 文件操作

详情栏按归档、下载、上传新版本、复制链接排序；归档与 Delete / Backspace 均先确认。首页与详情侧栏右键菜单保持相同操作，编辑输入时不触发归档快捷键。

## 品牌与版本命名

- 对外统一区分“微信小程序”“H5 本地版”和“JOJO（叫叫）托管版”；H5 本地版强调浏览器本地保存，JOJO 版强调内部交付和公开链接协作。
- 普通 H5 首页、详情页和各状态页的品牌标题均不显示 `for JOJO`；托管版通过 `isHostedPlatform` 明确开启该标记。
- JOJO 版沿用 H5 的蓝黑工具界面与主题黄交互色，只在标题旁增加克制的 `for JOJO` 小字，不另做独立大标志或宣传页。
- README 的版本说明必须同时写出入口、保存边界和适用场景；公开短链接明确为可转发链接，不能使用“私密分享”一类文案。

## JOJO 详情文件名编辑

- 标题保持纯文本，只保留悬停重命名；版本号、版本时间及切换入口统一放在评论区。
- 文件名旁使用 15px Phosphor `pencil-simple` 图标，桌面悬停或键盘聚焦时显示；触屏常显，点击区域 36px。
- 编辑框原位替换文件名，自动聚焦并全选；Enter/勾选保存，Esc/叉号取消。保存中禁用重复提交，失败保留输入并显示可重试错误。
- 名称限制为 1–120 个 Unicode 字符，拒绝空白、换行与控制字符。保存时不重建播放器；评论区的版本分组负责切换预览版本。

## 视觉方向

- 整体为偏蓝黑的工具界面，克制、清晰，避免纯黑造成压迫。
- 主题黄只用于主操作、选中、进度和关键反馈。
- 主要颜色：背景 `#0B0F14`、面板 `#121A23`、控件 `#1C2633`、主题黄 `#F2C94C`、主文字 `#F2F0E8`、次文字 `#7F8C9E`、描边 `#2A3646`。
- 圆角以 `10rpx / 20rpx` 两档为主，阴影统一为低透明度蓝黑色。

## 首页

- 导入区横向撑满，只保留图标和“导入 Rive 文件”。点击后再展示导入方式菜单。
- 文件行内容左对齐，封面小而略倾斜；操作箭头固定在最右侧方形区域。
- 箭头区不使用左分割线，右侧保留舒适内边距。
- 文件操作默认折叠，展开后只纵向展示发送、删除两项，文字居中；首页不提供“保存到电脑/手机”。
- 首页可点击元素统一提供即时放大与弹簧复位：操作箭头、菜单项、复制和反馈入口使用 `1.25×`，导入框和整行文件使用不遮挡相邻内容的 `1.025×`。
- 示例文件和用户文件共用删除操作与危险色；示例删除确认文案需明确“清除小程序本地数据后可恢复”。
- 新导入且尚未打开的文件显示倾斜的小型占位图；首次预览成功后再保存首帧封面，不在首页后台渲染。
- 网页版不再作为导入区下方的独立入口；首页底部无分隔线，单行承载“复杂文件用网页版更流畅：”、网址和复制图标。
- 底部整个单行容器左右各保留 `20px` 内边距，文字为 `24rpx`；界面网址省略协议头，仅显示 `mikeywa.site/rive-viewer/`，使用主题黄；末端通过 `42rpx` 黑色渐隐遮罩表示截断，遮罩与最右侧的 `60rpx` 方形深色复制按钮无缝衔接。
- “联系作者反馈意见”使用 `24rpx` 字号；复制网址成功后以“已复制网址”短提示确认结果。

## 预览页

- 自定义导航栏的标题和返回按钮必须在手机、Mac、Windows 均垂直居中；返回按钮点击区域不得进入电脑端窗口标题或拖拽区域。
- 电脑端直接恢复到预览页且没有上一页时，返回按钮仍必须回到小程序首页，不能表现为无响应。
- 电脑端导航按系统胶囊的 `top / height` 推导顶部补偿；返回按钮使用完整 `44×44px` 热区且不使用纵向负边距，标题与按钮共用 `44px` 内容基线。
- Mac/Windows 宽屏达到 `960px` 后使用同一页内的 `50% / 50%` 自定义分栏，不绘制中间分隔线；左侧保留文件列表，右侧复用完整预览内核。
- 桌面端缩窄时自动恢复独立详情页；独立详情页拉宽到阈值后回流到同页分栏，不保留微信原生双页容器。
- 一屏同时容纳文件信息、画布、播放控制和参数，不让控制区遮挡画布。
- 画布宽高遵循资源比例；背景色选项使用宽度为高度 `1.5×` 的短胶囊，兼顾辨识与点按。
- 用户只能拖动画布下方手柄改变高度，画布本身的滑动全部交给 Rive 交互。
- 按下手柄时原位操作行由 `48rpx` 增高到 `80rpx`，内容上下各留 `16rpx`（实际 `8px`），不新增浮层；左侧横排显示 `34rpx` 图标和 `26rpx`“完整”，中间横条加长至中间列宽并与两侧区域对齐，右侧横排显示同规格“铺满”。上下移动继续改变画布高度，左右移动只更新当前悬停项，松开时执行悬停项，停留在中间松开不改变缩放方式。
- 单击手柄也展开同一原位快捷行，但中间手柄维持灰色，不表现为按住高亮；展开后“完整 / 铺满”可直接点击生效，若没有继续操作则 `3s` 后自动收起。只有长按或发生拖动时，中间手柄才使用主题黄反馈。
- 手柄双击直接在“完整 / 铺满”两种缩放方式之间切换，并立即同步画布尺寸与点击坐标。小程序的双击时窗为 `500ms`，轻微移动容差为 `16rpx`，在必达的 `touchend` 内识别；超过容差的拖动、长按与模式选择会清空双击候选，禁止与后续合成 `tap` 串联。
- 播放控制左对齐、倍速居中、文件切换右对齐；按钮尺寸不互相挤压。
- 画布下方工具栏使用五等分布局：重播、播放/暂停、播放速度、上一个、下一个各占一格，组内与组外间距相同以保证五格实际等宽；小程序独立页、Mac 同页预览和 H5 使用同一结构比例。
- 微信小程序端五个控件必须作为 `.transport` 的非原生 `view role="button"` 直接子项；容器使用 Flex，每项固定 `width: 0; min-width: 0; flex: 1 1 0; margin: 0`。禁止在原生 `button` Grid item 上使用 `width: 100%`，避免部分微信 WebView 把宽度按整行计算并由倍速项覆盖翻页项。
- 所有功能图标统一采用本地 Phosphor Icons `Bold` SVG；小程序直接引用，H5 通过 `.app-icon` CSS Mask 按需加载。不混用 Regular、Fill、Duotone 或自绘路径。
- 小程序 Phosphor Bold SVG 在官方路径基础上统一增加 `8/256` 的同色光学校正描边，并适当放大工具栏图标，以补偿微信 WebView 在 `14-18px` 小尺寸下的抗锯齿变细；图标语义和路径仍保持 Phosphor Bold。
- 时间轴标签横向平铺并自动换行；H5 时间轴标签比通用标签左右各多 `14px` 内边距，当前项以黄色半透明背景进度表达状态，文字始终保持白色。OneShot 在终点强制填满，Loop 回绕，PingPong 按往返方向变化；切换动画时先归零，不能继承上一条时间轴的进度。
- Loading 居中显示环形百分比、阶段文案和细进度条；进入同步 Rive 解析前必须先让“正在初始化 Rive”刷新到画面，解析超时或资源失败后结束等待。
- 声音行位于“状态机输入”和“缩放方式”之间，仅在文件含音频时显示；复用 `parameter-tag`，默认“开启”使用主题黄选中态，“静音”使用普通态。
- 超过 8 MB 的文件将声音标签显示为“性能保护”；点击给出原因，不用警告红色打断预览。
- 声音标签沿用 `.96` 按压和 `180ms` 松手反馈，不新增图标或独立开关样式，保持参数区紧凑一致。
- iOS 音频性能档只改变内部渲染节奏：约 `30fps`、像素比不高于 `1.5`、状态文案最快每 `100ms` 合并更新，不增加额外视觉提示。
- 播放控件下方不再放状态小字；实时 FPS 紧跟播放时间显示，不再向用户显示首帧耗时。
- 渲染质量使用性能、平衡、高清三段控件；普通 H5 默认高清，JOJO 托管版保持平衡，微信小程序默认性能并记忆用户选择。复杂文件自动保护不使用警告红色，也不因默认高清而解除 DPR 与帧率上限。

## 交互与动效

- 常规按压缩放到 `.97`，参数标签按压缩放到 `.96`。
- 标签松手反馈使用 `180ms cubic-bezier(.22, 1, .36, 1)`。
- 手柄模式选择器使用 `420ms cubic-bezier(.22, 1.22, .36, 1)` 近似 Gentle 弹簧：操作行平滑增高，手柄从中间向两侧延长，左右选项分别向两侧滑出；收起沿同一曲线反向回弹，透明度在 `300ms` 内完成。默认手柄较粗（小程序 `8rpx`、H5 `5px`），展开后变细（小程序 `5rpx`、H5 `3px`）。
- 手柄两侧图文在各自三分之一容器中水平居中；当前项或悬停项的图标与文字同步使用主题黄，悬停背景为 `rgba(242, 201, 76, .14)`。背景使用与同页按钮一致的固定 `10rpx` 圆角，不显示描边、阴影、悬浮位移或 `50%` 椭圆圆角。
- 预览菜单所有可操作控件统一使用即时 `1.25×` 中心放大，按下进入约 `70ms`，松开以 `280ms cubic-bezier(.34, 1.56, .64, 1)` 弹簧感曲线复位；放大态临时提升层级，避免被相邻按钮裁切。
- 播放速度与文件切换按住 `150ms` 即展开菜单，菜单入场和退场均为 `150ms`；菜单外使用透明全屏点击层，点击空白处只关闭菜单，不穿透到底层画布。
- 文件菜单复用倍速菜单的按住滑选反馈：逐行测量真实命中区域，手指未松开时滑入文件行立即高亮，在该行松手后先收起菜单再打开文件；菜单外松手不误切换。
- 预览背景色块的高度保持 `40rpx`，宽度由 `40rpx` 增至 `60rpx`，使用全圆端短胶囊扩大点按面积；桌面嵌入预览按半尺寸同步。
- 文件卡进入预览的共享封面过渡使用 `320ms cubic-bezier(.22, 1, .36, 1)`。
- Trigger、已选标签和输入控件重复点击也必须产生可见反馈。
- 菜单使用 `root-portal + cover-view`，确保始终位于原生 Canvas 上方。

## 可复用约束

- 测试包仅改变交付形式，不为打包额外修改页面颜色、字号、间距或交互。
- 微信组件 WXSS 只使用 `:host` 和类选择器；原生 `button`、`image`、`view` 等统一补语义类，不使用标签选择器、属性选择器或后代标签选择器，避免样式被开发者工具拒绝。
- 手机全页和桌面分栏都复用 `preview-panel` 组件；组件内 Canvas、菜单和手柄测量必须使用绑定当前组件的 `SelectorQuery`，不能按页面模式决定是否 `.in(this)`。
- 用户选择 `.rev` 时使用明确的格式说明：这是编辑器备份文件，请先在 Rive 中导出 `.riv`；不使用笼统的“文件损坏”提示。
- 新增主要颜色前先确认现有色阶无法覆盖。
- 新增标签统一使用 `parameter-tag`，不另造相似按钮。
- 点击目标不小于 `60rpx`；纯装饰图标不得拦截触摸。
- 桌面端导航栏不得直接信任手机胶囊坐标；异常坐标使用 `72px` 安全留白，并在窗口尺寸变化后重新计算左右留白。
- Mac 宽屏详情使用同一页面内的深色双栏，不绘制浅灰或白色分隔线；两栏以相同 `#0b0f14` 背景直接接壤。
- 同页分栏的首页当前通过 `200%` 内容尺寸配合 `scale(.5)` 保持原布局；降低启用阈值前需先验证合成层显存、滚动栅格化和触摸命中，不把消除中线置于性能稳定性之上。
- 动效优先使用透明度、缩放和颜色，避免大范围持续位移。
- 超过首屏承载量的画板标签只先显示当前项与“展开其余 N 个”；展开时用标签背景显示百分比，完成后按原有规则多行平铺。
- 复杂文件性能降级优先使用较低 DPR、较低帧率和静态总览，继续沿用现有蓝黑与主题黄，不增加突兀的警告色。
- 小程序分享沿用微信右上角系统菜单，不增加诱导分享浮层；平台拒绝分享权限时只记录诊断信息，不用弹窗打断预览。
- 好友分享封面使用 Figma 节点 `163:729`：5:4 黑底、黄色圆形品牌标与双界面展示，压缩为 500×400 标准 RGB JPEG；朋友圈使用 1:1 透明底 PNG 圆形小程序图标。
- 分享兼容性排查不引入页面内备用分享按钮或无效 JSON 开关，保持现有界面与交互不变。
- 复制图标使用 Phosphor `copy-simple`，只有用户主动点击时才写入网页版地址；失败时提示长按网址手动复制。
- 隐私用途文案明确区分“写入”和“读取”：说明用户主动复制固定网址，并明确不读取剪切板已有内容。
- 分享图继续保持当前压缩尺寸；在不牺牲识别度的前提下，新增静态视觉资源应优先控制体积。`1.5 M` 是代码质量建议线，设计资源必须确保整体不触及单包 `2M` 上传限制。

## 独立 H5

- H5 延续蓝黑面板、主题黄选中态和紧凑参数布局，保持与小程序相同的控件认知。
- RIV 素材里的柔和内阴影、虚化边缘与光晕若依赖 Vector Feathering，视觉验收以 WebGL2 / Rive Renderer 为准；Canvas2D 的平涂硬边不是设计还原。性能、平衡、高清只调整分辨率与帧率，不能代替渲染器能力。
- H5 默认选中 WebGL2；参数区最后固定为“渲染引擎”，选项使用现有黄色选中标签，文案为“WebGL2 / 兼容模式”。手动切换或自动降级都会重建 Canvas，避免在同一元素上混用 WebGL2 与 Canvas2D 上下文。
- 浏览器本地版与 JOJO 版以 WebGL2 / Rive Renderer 为视觉准确性基线，并保留 Canvas2D 兼容模式。微信小程序为保证加载稳定性使用 Canvas2D；依赖 Vector Feathering 的柔边、虚化和内阴影以 H5 / JOJO 验收，小程序重点验收画面可见、控制、FPS、状态机与交互。
- 微信开发者工具普通编译并打开真实 `.riv`，可作为小程序 Canvas、FPS、画板、状态机和时间轴的基础视觉验收；目标 iPhone / Android 仍需继续验证长期性能与音频表现。
- WebGL2 失败 Toast 固定在底部安全区上方，最大宽度 `420px`、深蓝近不透明背景、`10px` 圆角、层级 `1500`，文案为“WebGL2 不可用，已切换到兼容模式”，约 `4.2s` 后消失；只说明已经发生的降级，不阻断继续预览。
- 手机首屏默认显示导入区或文件列表；进入预览后同时显示画布与参数，不做横向滑动标签。
- 预览详情不使用一级 Tab；画板、状态机、时间轴、输入、声音、完整/铺满、渲染质量和背景按顺序放在同一参数面板；文件下载和托管链接复制只放在右上角，不在参数区重复。手机使用顶部栏入口，`860px+` 两栏模式使用文件标题区右侧入口。
- H5 标签一行放不下时多行平铺；控制面板纵向滚动，不以横向滑动隐藏选项。
- H5 控制面板第一栏是全宽事件控制台。折叠态只露出绿色活动点、最新事件时间、类型和名称；点击后向下展开当前文件本次打开期间的事件历史，内部最大高度 `228px` 并独立滚动，长属性允许换行，不能撑出横向滚动。
- 事件类型使用固定语义色：`INFO` 为灰、`EVENT` 为洋红、`STATE` 为绿、`PLAY` 为正文色；主题黄只用于选中与可操作反馈。无事件时显示“等待 Rive 事件”，历史最多保留最近 `200` 条。
- 完整/铺满不仅切换黄色选中态，还必须立即重算画布对齐并刷新一帧；渲染与点击使用同一对齐矩阵。
- H5“完整”模式下，Rive 画布外框按当前画板比例居中收拢；Lottie 与 PAG 保持可调高度的预览窗口，动效内容在窗口内按源文件比例完整居中。“铺满”模式才允许内容裁切填满。
- H5 文件列表 Hover 背景施加在 `.file-row` 整行，必须连续覆盖内容区和最右侧操作箭头区。
- H5 文件列表底部将“小程序”入口和纯文本“反馈意见：杨皓棱”并排；反馈文字使用 `12px`，不带图标、背景或点击态。“小程序”悬停、聚焦或触屏点击后，从入口上方展开 `220px` 深色卡片，显示“Rive 预览台”和 `188px` 小程序码，动效使用 `220ms cubic-bezier(.22, 1, .36, 1)`。
- Canvas 全面接管内部点击、拖动和滑动；仅画布下方手柄可调整画布高度，单击展开选项并于 `3s` 后收起，双击在完整/铺满之间切换。
- 加载遮罩用居中百分比、阶段文案和细进度条；FPS 放在文件元数据的播放时间右侧，并与小程序保持一致。
- 用户导入素材不生成服务器端缩略图。托管根域名的首页、详情和侧栏加号都把选择或拖入视为明确上传动作；首个文件本机保存后立即打开，预览与上传并行。状态只跟随对应文件行：电脑代表仅本机、上云箭头代表上传中、云勾代表完成、云叉代表失败；图标是不可独立操作的状态信息，首页与详情侧栏的文件主区域整体负责选中并打开，点击图标也执行同一打开动作。上传进度、错误和重试自动在行内展开，不再额外放置成功卡片；菜单与重试按钮维持独立命中。旧 `/rive-viewer/` 只显示本地状态。
- 本地文件和成功查看的公开文件都在当前浏览器生成 `160×120`、质量约 `.58` 的 WebP 首帧封面；允许轻微模糊，以列表即时出现和低存储占用优先。远端 `.riv` 本体不因“最近文件”而长期缓存。
- 首页始终保持原有纵向布局；`860px` 及以上打开文件时，首页收入左侧主区，右侧挂载预览面板。
- 跨过 `860px`、或宽屏从首页打开文件时，首页列宽、透明度和水平位移用约 `260ms` 的缓出过渡表达展开/收起；系统开启“减少动态效果”时立即切换。
- 预览左上角统一使用返回箭头回到首页文件列表，`Esc` 完全等效；公开链接的加载、失败、归档以及评论输入聚焦状态也遵循同一行为。
- 页面右上角使用键盘图标打开快捷键浮窗；细粒度鼠标 Hover 和键盘聚焦直接展示，触屏点击可固定。固定态按 `Esc` 只关闭浮窗并取消按钮焦点，下一次 `Esc` 才返回首页。说明项保持单行、键帽对齐，不常驻占用预览空间。
- 快捷键浮窗由页头最高交互层承载，必须覆盖 Rive 画布和预览内容；层级通过 `--z-header`、`--z-popover` 统一维护。
- H5 页头不显示平台文字标签，右侧只保留有实际操作价值的键盘入口。
- H5 首页底部使用与小程序一致的低强调反馈入口；点击后复制作者微信号，并用一行黄色状态文字确认结果。
- H5 首页和预览控件同步小程序的按压回弹、两项文件菜单、手柄单击展开、参数顺序和 `1.5:1` 背景色块；H5 不提供不可恢复移除，浏览器“发送文件”优先使用系统分享，不支持时回退下载。
- 文件列表操作箭头默认隐藏，仅在鼠标悬停、键盘聚焦、触屏设备或菜单展开时显示。
- 浏览器 favicon 使用圆角矩形的 `64×64` WebP，同时提供 PNG 回退和缓存版本号；中央羊石符号保持原样，只把黄色底板补成正方形。iOS 主屏单独使用不透明 `180×180` 方形源图，由系统应用圆角遮罩；同一圆角矩形图标显示在页面左上角标题前。
- H5 只保留 Vite 静态构建；旧本地预览使用 `/rive-viewer/`，托管域名使用根路径 `/`。HTML 不缓存，哈希资源和版本化 WASM 使用一年 immutable 缓存。
- 生产发布只替换静态产物和缓存规则，不临时调整颜色、排版或动效；线上资源必须与已验收的 `dist-static` 字节一致，避免发布过程引入视觉漂移。
- 小程序不内嵌 H5；首页底部只展示正式网址并提供用户主动复制。

## 文件版本视觉

- “上传新版本”位于下载左侧，桌面显示白色上传图标和完整文字；下载图标同为白色，主分享按钮仍保留黄色底与深色图标以保证对比度。
- 文件名有多个版本时才显示下拉箭头；菜单按新到旧排列，每项显示“版本 N”、原文件名和精确到分钟的上传日期，当前项用左侧细黄线标记。
- 只有两个及以上版本时，评论才按版本标题分组；单版本直接展示普通评论列表。分组时当前预览版本展开、其他版本折叠，标题点击既切换文件版本，也切换展开的评论组。
- 渲染质量、缩放方式和渲染引擎的选中态复用时间轴低亮样式：深色底、淡黄色边框和浅色文字，不使用高亮实心黄。

## 多格式预览视觉

- 上传区统一写“Rive、Lottie 或 PAG”，文件名与时间轴区显示真实格式；不为 Lottie、PAG 伪造画板、状态机、输入、事件或渲染引擎控件。
- Lottie 与 PAG 沿用现有蓝黑画布、背景色、完整/铺满、播放、重播、倍速、进度、FPS 和评论结构；格式切换不改变详情页信息层级，正式站与 Beta 保持一致。
- 跨 Rive、Lottie、PAG 切换时必须重建格式对应的 Canvas DOM 节点；不得让 WebGL2、WebGL1 或 Canvas2D 在同一节点上争用上下文。重建不改变画布外框、背景、手柄或控制区位置。
- Lottie 使用覆盖在画布区内的完整 Canvas 运行时并关闭渐进加载，PAG 直接使用主 Canvas；两者的外层窗口都可通过原手柄调高，内部“完整”保持源比例，Canvas 必须紧贴窗口内容区且不得横向越界。
- PAG 超过 `10 MiB` 时使用明确错误文案“PAG 文件不能超过 10 MiB”，在读取与上传前阻断，不使用模糊的解析失败提示。

## 重构视觉保护线

- 性能重构不得改变现有蓝黑面板、主题黄、Phosphor Bold、五等分工具栏和 Gentle 手柄反馈。
- 小程序独立详情与 Mac 嵌入预览应以同一份预览组件为视觉真源，页面壳只处理路由、分享和布局差异。
- FPS、时间轴和拖拽高度等高频状态应与静态文件列表、参数面板隔离，避免为提升性能而删减可见反馈。
- 拖动画布尺寸时只改变外框；松手后再同步 backing canvas，避免拖动过程中反复分配画布内存。
- 动效时长、手势容差、断点和渲染档位应集中配置；双端允许按平台覆盖，但不得散落复制。

## 托管模式设计

- 延续现有蓝黑单主题、主题黄和本地 Phosphor Bold 图标，不新增独立后台视觉体系。
- 新域名根路径直接展示托管平台，旧域名 `/rive-viewer/` 继续保留本地预览和原 Origin 文件库。
- 托管域名的首页上传框、详情页整区拖入和窄侧栏加号都是明确上传动作；旧本地入口仍只写入浏览器。托管域名内已保存但未上云的历史文件可从菜单点击“上传并生成链接”，并复用同一条行内上传链路。
- 上传入口必须明确写出上传后会生成公开链接，不能把临时稿静默上传；公开链接对所有拿到链接的人可见并可评论。
- 桌面和手机公开详情都把唯一评论栏放在右侧控制区，紧跟第一栏事件控制台；不占用左侧文件栏，不重复公开链接卡，也不把评论推到参数区末尾。
- 评论只保留一个纯文本正文输入区。聚焦时在框上方显示系统分配的 32 组“萌萌森林”身份；头像和昵称都可点击修改本机偏好。昵称最多 `12` 个 Unicode 字符；头像居中裁成 `64×64 WebP`，关闭原图解码并清空文件输入，不保存原始图片。无自定义时仍使用默认动物头像；列表统一以 `32×32px` 圆形裁切展示。发表失败保留正文并允许重新发表；列表读取失败独立提供“重新读取评论”，失败时不显示空态。
- 输入框内的发表按钮必须高于可编辑层，保持整块可点；普通回车发表，`Shift + Enter` 或 `Command + Enter` 换行。IME 组字的回车仅用于确认候选字，不触发评论提交。
- 评论线程以三位分享短码为唯一归属。切换文件时立即清空旧线程并只接受目标短码返回的数据；已有云端短码的文件必须打开对应公开文件，不能为了快而用本地副本配上上一文件的评论。相同字节再次上传也生成新短码，保证每次交付可拥有独立评论区。
- 活跃评论右侧使用普通深色“归档”按钮，不用危险红色；归档评论默认折叠为低强调行，保留 `32×32px` 头像、昵称和“评论已归档”状态，展开后才显示原文与“恢复”。归档和恢复不改变评论顺序。
- 上传、分享页和评论分别覆盖等待、成功、空、网络失败、限流、超限和重试状态；复制失败时提供可选中链接，不静默失败。
- 上传框和详情页接受点击或拖放，同一批文件顺序上传以匹配服务器写操作限速；每个文件独立保存百分比、错误与重试目标，同名文件也只能按本地 `file.id` 更新自己的状态。完成后只保留体积后的云勾，三位短码、复制和打开操作收进该文件菜单。
- 托管文件打开后，详情右上角只保留下载和黄色“复制分享链接”两个操作，不显示快捷键提示或再套一层详情分享弹窗。桌面复制按钮与下载同高 `42px`、间距 `8px`；手机 `520px` 以下只收起下载文字，复制文字始终完整。
- 复制成功后按钮原位切换为普通深色控件样式、单独的打钩图标与“已复制”，不保留黄色强调；宽度保持 `122px`，约 `2.2s` 后复位。失败时原位显示“复制失败”。反馈只用于表达操作结果，不移动焦点、不改变布局。
- 标题右侧使用 `9px`、`var(--muted)` 的 `for JOJO` 作为叫叫版署名，不添加胶囊、边框或背景。`380px` 以下详情页隐藏长标题但保留图标和署名；首页空间充足时完整显示标题。底部“反馈意见：杨皓棱”是 `12px` 纯文本，不使用图标、Hover 或复制交互。
- 公开链接直接使用根路径 `/<3 位 Base62>` 并显示 `noindex`，旧 `/s/<短码>` 永久跳转到新地址；短码大小写敏感，`api` 为保留码。短码只服务于易复制，不宣传为安全凭证。复制与展示必须保留原始大小写，界面文案要明确公开链接可被转发，不能称为私密链接。
- 服务端全部公开中、本机文件与当前浏览器成功查看或发表评论的非示例公开文件合并为一个“最近文件”列表；按最后打开、评论或上传时间倒序，按短码和本地映射精确去重，不按文件名猜测。远端最近记录最多保留 `20` 条；清除站点数据后本地活动时间与缩略图一同消失，不跨浏览器同步。
- 文件操作统一使用“归档”，不出现“删除文件”。归档前的二次确认同时显示文件名和“归档后可恢复”，避免使用危险红色制造永久删除暗示。
- 首页标题右侧提供 `34px` 高的紧凑“已归档”按钮和数量，不直接展开归档列表。数量使用 `11px` `var(--muted)` 普通文本，不使用黄色背景、圆角或徽标。点击后使用现有深色模态层展示完整归档文件列表、复制与恢复；Esc、遮罩空白和关闭图标都可关闭，Tab 留在弹层内，关闭后焦点回到入口。恢复后列表与数量原位更新，原短链接、评论和创建时间保持不变。
- 归档后的公开分享页显示“文件已归档”，停止播放和新增评论；恢复后原链接自动重新生效。
- 播放速度图标固定 `18×18px`、不缩放且不位移；`.speed-select` 使用 `overflow: hidden`。`390×844` 和 `1440×900` 实测图标四边都在 `38px` 高按钮范围内。
- 归档确认、公开链接和评论复用同一组深色对话框与主题黄主按钮；上传进度不使用对话框或独立成功卡，始终贴在对应文件行下方。归档不使用危险红色，上传进度条只使用单色主题黄，不使用渐变。
- JOJO 托管版的 H5 首次打开文件默认“完整”（`contain`），旧 `/rive-viewer/` 本地版仍默认“铺满”（`cover`）；用户在当前会话中仍可自由切换，不新增持久化覆盖默认值。
- 公开文件冷加载页显示文件名、体积和真实字节下载百分比，进度条使用单色主题黄。连接服务器 20 秒无响应或已开始下载后 30 秒无新字节时，收起 Loading 并给出中文错误与“重新加载”；持续有数据的慢网不设总时长上限。
- 下载速度属于托管基础设施边界，不用假进度掩盖。当前主机没有应用或系统层 GET 限速，但公网实测仅约 `1–2 Mbps`；界面始终展示真实字节进度，不能把慢速误写成“文件解析中”。大文件提速优先升级腾讯云公网带宽或使用同区域 COS/CDN，不通过改变动画、颜色或延长假进度解决。

- 桌面详情页在 `860px` 以上保留 `184px` 文件窄栏，顶部固定“最近文件 / 数量 / ＋”，列表独立滚动；移动端不显示窄栏。黄色加号按钮使用 `#0b0f14` 近黑色图标，保证品牌黄上的清晰对比。当前项仅使用一条独立的 `3px` 主题黄圆角竖线和轻微深色底，禁止黄色内阴影。
- 详情侧栏的顺序在当前详情会话中保持稳定：点击缩略图、标题或使用上一个/下一个只切换黄色选中线，不更新最近活动时间、不置顶，也不自动展开上传状态。首页打开、评论和上传仍可更新“最近文件”排序。

## 黑客松宣传视觉

- 宣传图必须以 `vGd` 真实页面为视觉真源：蓝黑界面、主题黄分享按钮、绿豆角色、播放控件、事件条和评论区；禁止换成通用 3D 人物或虚构产品面板。

- 大众投票优先使用“别再发录屏了”的痛点反差；专业答辩优先使用“不只看画面，还能看懂交互”。宣传图可以出现钉钉会话语境，但不使用官方钉钉标识，也不暗示原生集成。

## JOJO 横屏检查布局

- `1194px+` 使用左预览、右检查的可调双栏；桌面先把保持文件原始宽高比的画面扩到约 `800px`，再让最小 `360px` 的右栏吸收余量。左栏画布首次打开时填满视窗高度，画布下方 `32px` 手柄始终保留，首次拖动从当前满高尺寸接管。中缝默认低对比，Hover、聚焦或拖动时变为 `3px` 主题黄。
- 最近文件栏默认 `184px`，支持在 `160–360px` 间拖动或键盘调整；分隔线沿用低对比到主题黄的反馈。文件名被截断时，Hover 或聚焦在栏外显示深色小浮层，不挤压缩略图、状态图标和当前黄线。
- 右栏评论正文使用 `14px / 1.6`，头像独立在左列，昵称与正文在右列仅留 `2px` 垂直间距。时间靠右，一周内使用相对时间，之后显示绝对日期。输入框默认 `46px` 单行高度，发表按钮内置；空框 Hover 显示 `2×18px` 主题黄闪动光标，聚焦后由同色真实 caret 接替。
