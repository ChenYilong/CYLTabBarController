# react-native-cyltabbar

CYLTabBarController (iOS) and its Android port as a React Native Fabric component

## Installation


```sh
npm install react-native-cyltabbar
```


## Usage


```js
import { CyltabbarView } from "react-native-cyltabbar";

// ...

<CyltabbarView color="#32a852" />
```
