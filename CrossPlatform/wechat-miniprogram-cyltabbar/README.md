# wechat-miniprogram-cyltabbar

CYLTabBarController for WeChat Mini Program: `cyl-tab-bar`, a custom tab bar component configured with the same keys as
the iOS and Android libraries ([docs/Configuration-File.md](../../docs/Configuration-File.md)), and an example mini
program. Full documentation, the supported keys and the score: [docs/WeChat-Mini-Program.md](../../docs/WeChat-Mini-Program.md).

## Run the example

1. Install [WeChat DevTools](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) and log in.
2. Import this folder (it holds `project.config.json`, AppID `wx5e29c9d33906f074`; use your own AppID for your app).
3. Compile. The tab bar reads `miniprogram/shared/configuration.js`, a copy of
   `Example-Shared/Configurations/cyl_tabbar_configuration.json`.

After changing `Example-Shared/Configurations`, run `npm run sync` (`npm run sync:check` fails when the copy is out of
date). Tests of the configuration reader: `npm test` (Node 18+).

## Use the component

```json
// app.json
{ "tabBar": { "custom": true, "list": [{ "pagePath": "pages/home/index", "text": "Home" }] } }
```

```xml
<!-- custom-tab-bar/index.wxml -->
<cyl-tab-bar configuration="{{configuration}}" selected-identifier="{{selected}}" bind:select="onSelect" />
```

Events: `select`, `reselect`, `plustap`, `loginrequired` (detail: `index`, `identifier`, `pageIdentifier`,
`pageParameters`, `context`, `isPlusButton`). Methods: `cyl_selectIdentifier`, `cyl_showBadgeValue`,
`cyl_showBadgeDot`, `cyl_removeBadge`, `cyl_setThemeIdentifier`, `cyl_themeIdentifiers`.

## Layout

| Path | What |
|:---|:---|
| `miniprogram/components/cyl-tab-bar/` | The component; `cyl_configuration.js` reads the configuration (no wx API, tested in Node) |
| `miniprogram/custom-tab-bar/` | The example's custom tab bar: passes the configuration, switches pages, follows the app state |
| `miniprogram/pages/` | Home, Message, Post (the plus button's page), Discover (`web`), Me (demo rows) |
| `miniprogram/shared/` | Generated by `scripts/cyl_sync_shared.js` from `Example-Shared/Configurations`; do not edit |
| `test/` | Node tests of the configuration reader |

No code was copied from the projects listed as references in the documentation: see [NOTICE](NOTICE).
