# include

[EN] Intentionally without headers. Swift Package Manager expects this folder to exist for every target whose path is `CYLTabBarController/`; the real public headers of the C targets are in `Package/ObjC/include` and `Package/Engine/include` (docs/Swift-Migration.md, phase 3).

[CN] 有意不放头文件。Swift Package Manager 要求路径为 `CYLTabBarController/` 的每个目标都存在此文件夹；C 目标真正的公开头文件位于 `Package/ObjC/include` 与 `Package/Engine/include`（docs/Swift-Migration.md，第 3 阶段）。
